## 💛 Story

Memory Garden was built in a single AI conversation — from idea to live game — by AutoGPT AutoPilot. It was designed with love for people with dementia: no timers, no pressure, just gentle encouragement and soft rewards at every step.

## 🎮 How to Play

Choose colors, match pairs, and spot the difference across 9 calm rounds. A friendly voice guides you at each step, and every correct answer is celebrated with chimes and stars. ✨

## 🌿 Exercises

- 🌸 **Flower Color** — What color is this flower? Tap the right answer.
- 🦋 **Matching Pairs** — Flip cards to find matching emoji pairs.
- 🔍 **Spot the Difference** — Tap where two garden scenes differ.

## 🔧 Technical Overview

| Feature | Detail |
|---|---|
| Format | Single-file `index.html`, no dependencies |
| Audio | Web Audio API — procedural chimes & ambient tones |
| Voice | SpeechSynthesis API — calm, slow voiceover |
| Graphics | Canvas 2D — hand-drawn garden scenes |
| Input | Touch + mouse — mobile & desktop |
| Animations | CSS keyframes — burst, ripple, glow effects |

## 🖥️ Run Locally

```bash

open index.html
```

Or clone and serve:
```bash
git clone https://github.com/plagerismorrevolution/memory-garden.git
cd memory-garden
python3 -m http.server 8080
# Open http://localhost:8080
```
